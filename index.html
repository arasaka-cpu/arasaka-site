The pitch

Arasaka is a desktop OS you cannot wreck by accident. The root filesystem is immutable, the boot chain is signed, your disk is sealed to the hardware's TPM, and updates are atomic — either you get the whole new system, or the old one.

🛡

Hardened core

Per-slot signed Unified Kernel Images enforced with Secure Boot. If it didn't come from our signing key, it doesn't run.

🔐

Sealed storage

LUKS2 encryption on /data, auto-unlocked by the TPM2 (PCR 7+11) with recovery-key fallback. Re-seal and heal on every boot.

⚡

Atomic updates

A/B slots + multi-source OTA with automatic failover. Updates land fully-formed or not at all, and rollback is a reboot.

🖥

Dev / desktop ready

Dev /data (no locking), COSMIC desktop, browser via the web. Snap to snap, each sealed slot is a self-contained system.

Why

Most desktops mutate constantly — packages land, configs drift, and one bad command can brick an evening. Arasaka flips the model: the system is a disposable, verifiable artifact.

🧱

Immutable by design

squashfs + verity rootfs, read-only. There's no pacman in the image, no shell into /usr. If you can't touch it, you can't break it.

📦

Built once, shipped twice

A single CI pipeline produces both the OTA bundle and the live ISO, each with sha256 + gpg signatures checked before anything runs.

🧠

Fail safe

Boot failures auto-rollback to the last good slot. Updates are fully applied before switching, so a bad release never strands your device.
