Install

1 · Assemble split parts (GitHub assets only):

cat arasaka-*.iso.part.* > arasaka.iso

2 · Verify the sha256 from the .parts.json manifest:

sha256sum arasaka.iso # compare with the manifest value — signatures matter

3 · Write to USB:

sudo dd if=arasaka.iso of=/dev/sdX bs=4M status=progress oflag=sync

4 · Boot the ISO in UEFI mode — Secure Boot on, this is not a suggestion. The live system lets you flash the image or run the installer.

Notes

Files exceeding GitHub's 2 GiB per-asset cap are split into 1 GiB .part.NN chunks with a manifest. Prefer the B2 direct ISO when a single-file download is easier — same bits, same sha256, one URL. OTAs (devices already running Arasaka) never touch this page; the device fetches signed bundles itself.
