How it works

The button first asks the CDN worker for the current ISO manifest. If Backblaze B2 has the single-file image, it streams from there — no assembly needed. If B2 is unreachable, the worker instead fetches the GitHub release's split parts (each capped at 1 GiB), reassembles them in order, and streams the one ISO. Either way the browser hashes every byte it receives and you see verified only when the sha256 matches the release manifest.

No JavaScript runs the pretty page — only this button needs it, and the heavy lifting (assembly, checksums) happens off-device or as a pure stream.

Install

1 · Write to USB:

sudo dd if=arasaka-<date>.iso of=/dev/sdX bs=4M status=progress oflag=sync

2 · Boot the ISO in UEFI mode — Secure Boot on, this is not a suggestion. The live system lets you flash the image or run the installer.
