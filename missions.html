/data sealed to PCR 7+11, auto-unlocked at boot, recovery key + self-healing re-seal. Keys bind to this image and this hardware.

RAUC A/B updates. Client prefers B2, auto-falls back to the GitHub rolling release, and heals the preferred source over time.

Immutable rootfs (squashfs + verity)DONE

Read-only, hash-verified rootfs. No package manager in the image; the system is a pure artifact.
